**Short answer:** in the PAO system, every two-digit number from 00 to 99 gets a **person**, an **action** and an **object**. To memorize six digits, you take the person from the first pair, the action from the second and the object from the third, and combine them into one scene. So 12-34-56 might become *Einstein juggling a banana*: six digits in a single image.

## How does PAO work?

Start with a table where each number has all three parts:

| Number | Person | Action | Object |
|---|---|---|---|
| 12 | Albert Einstein | writing equations | chalk |
| 34 | a clown | juggling | juggling pins |
| 56 | a monkey | peeling | a banana |

To memorize **123456**:

- **12** → the *person*: Einstein
- **34** → the *action*: juggling
- **56** → the *object*: a banana

**Scene:** Einstein juggling a banana.

To memorize **563412**, you'd use the same three numbers in a different order: a monkey (56) juggling (34) chalk (12). Because each position uses a different part, the order of the digits is built into the scene.

## Why is PAO so efficient?

With a simple number system, one image usually holds two digits. A PAO scene holds six, so a 24-digit number needs just four scenes. Place those scenes along a [memory palace](/blog/build-your-first-memory-palace) and you can recall long numbers in order.

## How to build your PAO list

Building 100 people, 100 actions and 100 objects takes time, so most people do it in stages.

1. **Pick a way to choose people.** Many people use initials: the [Major System](/blog/major-system-memorize-numbers) (12 = T-N) or the Dominic System's letters (12 = A-B). Others just pick whoever comes to mind for the number.
2. **Choose people you can picture instantly:** family, friends, athletes, characters.
3. **Give each person a signature action and object** that clearly belongs to them: a chef chopping with a knife, a tennis player serving with a racket.
4. **Make every action and object distinct.** Two people who both "run" will blur together.
5. **Start with 00–19,** practise until each is instant, then add more.

## How PAO is used for playing cards

Memory competitors often give each of the 52 cards its own person, action and object. Three cards then make one scene: the person from the first card, the action from the second, the object from the third. A full deck becomes 17 scenes plus one leftover card, which fits neatly along a memory palace route.

## PAO vs the Dominic System

The [Dominic System](/tactics/dominic-system), created by eight-time World Memory Champion Dominic O'Brien, is a close relative. It turns digits into letters (1 = A, 2 = B…) and uses those as a person's initials. Classic Dominic combines a person and an action (four digits per image); PAO adds the object, for six.

## Is PAO worth learning?

If you want to memorize long numbers or decks of cards, yes, but it's an advanced technique. If you're new to memory techniques, start with the [Major System](/blog/major-system-memorize-numbers), which needs no setup. Once you're comfortable turning numbers into images, upgrade to PAO.

## Frequently asked questions

### What does PAO stand for?

PAO stands for Person, Action, Object. Each two-digit number is assigned one of each, and they're combined into a single memorable scene.

### How many digits does one PAO image hold?

Six: the person from the first two digits, the action from the next two, and the object from the last two.

### How long does it take to build a PAO system?

Creating a full 00–99 list usually takes a few weeks, and becoming fluent with it takes longer. Building it gradually, ten numbers at a time, keeps it manageable.

### What is the difference between PAO and the Major System?

The Major System turns digits into words using consonant sounds, usually two digits per image. PAO uses a pre-learned person, action and object for every number from 00 to 99, packing six digits into one image.
